# نظام البرنس جروب للفواتير والمخزون

نسخة جاهزة للرفع على GitHub وتشغيلها كصفحة ويب.

## التشغيل محليًا
افتح ملف `index.html` مباشرة من المتصفح.

## الرفع على GitHub Pages
1. اعمل Repository جديد على GitHub باسم مثل: `elprince-system`.
2. ارفع الملفات الموجودة هنا: `index.html` و `README.md`.
3. افتح Settings > Pages.
4. اختار Branch: `main` ثم Folder: `/root`.
5. اضغط Save.
6. GitHub هيطلع لك رابط مباشر للنظام.

## ملاحظات مهمة
- النسخة الحالية تحفظ البيانات داخل المتصفح/localStorage.
- لو فتحتها من جهاز آخر لن ترى نفس البيانات إلا بعد تحويل التخزين إلى قاعدة بيانات أونلاين مثل Firebase أو Supabase.
- المرحلة التالية المقترحة: ربط Firebase للمزامنة بين الأجهزة.
